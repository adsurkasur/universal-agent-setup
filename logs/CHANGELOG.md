# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-10-21

### Added
- **9 New Unified Skills** (total skills increased from 174 to 183):
  - `better-icons`: Fast icon search & direct codebase export across 200k+ icons.
  - `hallmark`: Next-gen design taste & production frontend layout blueprints.
  - `humanizer`: AI writing pattern removal based on Wikipedia's signs of AI writing.
  - `impeccable`: Design director-level craft floor & visual polish playbook.
  - `lottie-maker`: Inspection, creation, diagnostic, and portable Lottie JSON animation bundles.
  - `motion-design`: Motion principles, Disney principles adapted for UI, choreography, and brand motion.
  - `stop-slop`: Elimination of formulaic AI prose patterns, adverbs, and filler phrases.
  - `taste-skill`: Anti-slop frontend art direction and visual inspector from 247 gallery sites.
  - `framer-motion`: Comprehensive production guide for Framer Motion and `motion/react` v12+.
- **`better-icons` MCP Server**:
  - Registered across Antigravity, Claude Code, Claude Desktop, and Codex runtimes.
- **Activity & Decision Logs**:
  - Initialized `logs/ACTIVITY_LOG.md`, `logs/DECISION_LOG.md`, and `logs/CHANGELOG.md`.

### Changed
- Rebuilt `agent-setup-bundle.zip` with 183 skills and 6 MCP server templates.
- Updated documentation in `README.md` and `AGENTS.md`.
